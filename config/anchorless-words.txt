# 无检索锚点词表 —— dt router L0 提前拦截（early-exit）用
#
# 每行一个词（CJK 词条 / 英文词均可），`#` 开头为注释行，空行忽略。
#
# 判定逻辑：当一条查询（闲聊闸放行后）经 jieba 切词、去掉虚词后的**内容词**
# 全部落在本表里（或没有内容词）时，判定该查询没有可检索的具体对象
# （无代码符号/文件名/配置项/业务实体），直接返回「无需检索」，省掉一次 KG 搜索。
# 例如：
#   - "帮我实现"             -> 内容词只剩 [实现]（在表）        -> 拦截
#   - "帮我检查确定的原因，分析当前项目下的代码" -> [检查,确定,原因,当前,项目,代码] 全在表 -> 拦截
#   - "帮我检查支付超时的原因" -> [检查,原因] 在表 + [支付,超时] 不在表 -> 放行检索
#
# 注意：
#   1. 本文件是**叠加**语义（只增不减）——文件中的词会与内置默认词表做并集合并，
#      不会因为只写了几个词就丢掉内置默认的拦截覆盖；想新增词只需往本文件加行。
#      内置默认词表见 src/interfaces/cli/router.rs 的 GENERIC_ANCHORLESS_WORDS。
#   2. 查找顺序（与闲聊词表 casual-words.txt 一致）：
#      1) 环境变量 DT_ANCHORLESS_WORDS_FILE
#      2) <CWD>/config/anchorless-words.txt
#      3) ~/.config/digital-twin/anchorless-words.txt
#      4) <可执行文件目录>/config/anchorless-words.txt
#   3. 真实技术/业务词（支付/订单/缓存/接口/幂等/超时/模型/api/redis 等）**绝不入表**，
#      否则会误拦"支付超时怎么配置 / 接口怎么了 / 服务怎么了"等有效查询。
