## 关键发现

### 1. JSON 生成不可靠

**问题**：即使 temperature=0.1，仍有 40% 的 JSON 格式错误

**失败模式**：
```json
// 失败案例1：缺少引号
{
  "entities": [
    {
      name: "Hermes Agent",  // ❌ 缺少引号
      ...
    }
  ]
}

// 失败案例2：多余的括号
{
  "relations": [
    {
      {"head": "A", ...}  // ❌ 多了一个 {
    }
  ]
}
```

**现有修复措施**：
- 正则去除双括号
- 去除注释
- 但仍有 40% 失败

---

### 2. 结果波动较大

**实体波动**：17-20 个 (17.6% 波动)
**关系波动**：15-23 个 (53% 波动)

**对知识图谱的影响**：
- 每次运行可能缺失不同的实体/关系
- 需要多次运行并合并结果
- 或者用更高级的模型（如 GPT-4、Claude）

---

### 3. 稳定性取决于实体重要性

**核心实体**（文档中明确描述）：
- 100% 稳定出现
- 类型标注一致

**边缘实体**（上下文推断）：
- 波动较大
- 可能被遗漏或类型不一致
