Test Project for Digital Twin Build Pipeline
=============================================

This directory contains a standardized set of files used by
`dt build --test` to verify the build pipeline.

File types included:
- Java (.java): parsed for methods and classes
- Python (.py): parsed for functions and classes
- TypeScript (.ts): parsed for functions, interfaces, and classes
- JavaScript (.js): parsed for functions and classes
- HTML (.html): scanned as a source file
- CSS (.css): scanned as a source file
- Vue (.vue): scanned as a source file (single-file component)
- YAML (.yaml): scanned as a source file
- XML (.xml): scanned as a source file
- Text (.txt): stored as a document node
- Go (.go): parsed for functions and structs
- PHP (.php): parsed for functions and classes
- Rust (.rs): parsed for functions and structs
